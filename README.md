# 🚗 Vehicle Management System

A web-based Vehicle Management System developed using PHP, MySQL and CSS. This application is designed to manage vehicle-related information and maintain vehicle records through a simple web interface.

## ✨ Features

- Manage vehicle information.
- Add new vehicle records.
- View vehicle details.
- Update existing vehicle information.
- Delete vehicle records.
- Store and manage vehicle data using MySQL.

## 🛠️ Technologies Used

- **Backend:** PHP
- **Database:** MySQL
- **Frontend:** HTML, CSS

## 🎯 Project Objective

To provide a simple and organized platform for managing vehicle information and maintaining vehicle records efficiently.
